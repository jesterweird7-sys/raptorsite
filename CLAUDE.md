# Контекст для агента

Это фронтенд веб-приложения РАПТОР. Самостоятельный проект: собирается и
запускается целиком локально, внешние данные приходят через мок.

## Команды

```bash
npm ci                 # зависимости
npm run dev            # http://localhost:5173/app/  (нужен запущенный npm run mock)
npm run mock           # локальный API на 127.0.0.1:8091
npm run typecheck      # tsc --noEmit — запускать перед каждым коммитом
npm run build          # dist/
npm run check <url> <w> <h>   # скриншот + проверка переполнения и ошибок консоли
```

Минимальная проверка готовности изменения: `typecheck` чистый, `build` собирается,
`check` на 390 и на 1440 без горизонтальной прокрутки и без ошибок консоли.

## Что где лежит

- Маршруты и навигация — `src/lib/router.ts` (хэш-роутер), раскладка страниц в `src/App.tsx`.
- Все типы ответов и вызовы API — `src/lib/api.ts`. Один источник правды по форме.
- Состояние табло, карточки, журнала, фильтров, подписки и SSE-транспорт — `src/lib/live.ts`.
- Состояние пользователя, линии дня, дневника, админа — `src/lib/store.ts`.
- Переиспользуемые поверхности — `src/ui/kit.tsx` (Panel, Button, Chip, Verdict,
  Ring, ProbBar, Sheet, TabBar, Counter, Skeleton).
- Экраны мобильного контура — `src/screens/index.tsx`, живого сканера — `src/screens/live.tsx`.
- Настольные страницы — `src/site/`.
- Стиль живёт в трёх файлах: `tokens.css` (переменные), `glass.css` (мобильные
  поверхности), `site.css` (настольная сетка).

## Правила

1. **Токены вместо новых значений.** Цвета, радиусы, отступы, тайминги берутся из
   `tokens.css`. Локальные значения в компонентах допустимы только для размеров
   под конкретную сетку.
2. **Никаких выдуманных чисел.** Пустое значение показываем «—», а не нулём.
   `probability` — доли 0..1, `evPct` — проценты. Не перемножать их между собой.
3. **Свежесть данных считает сервер** (`ageSeconds`), клиент добавляет свои часы.
   Не парсить даты из человекочитаемых строк вида «15:42» — для этого есть
   отдельное машинное поле.
4. **Анимация обязана быть уважительной:** всё уже учитывает `prefers-reduced-motion`
   через CSS и `Counter`. Новые анимации — тоже через `motion` с
   `ease: [0.22, 1, 0.36, 1]` и длительностью 0.2–0.45 с.
5. **`grid`-дети требуют `min-width: 0`**, иначе широкое содержимое растягивает
   всю страницу. Проверить после любой правки сетки: `npm run check` на 390 px.
6. **Один сигнал на событие.** Если несколько сценариев ведут к одному — показываем
   главный, остальные подписываем подтверждающими. Не дублировать строки.
7. **Мобильный и настольный экраны — один источник данных.** Настольная версия
   (`src/site/`) не должна заводить своё состояние: тот же `useLive`/`useStore`.

## Чего не делать

- Не править `dist/` и `public/fonts` — это артефакты сборки и бинарные ресурсы.
- Не тащить в репозиторий ключи, `.env`, токены и реальные данные пользователей.
  В `mock/fixtures.json` только вымышленные матчи и команды.
- Не добавлять UI-библиотеки: все поверхности свои, одна стекло-рецептура.
- Не переписывать `src/lib/api.ts` «под себя» — типы отражают контракт, а не вкус.

## Права

Репозиторий приватный, лицензия собственная (`LICENSE`): работать могут только
добавленные участники, копировать и распространять нельзя.
