# РАПТОР · веб-приложение

Живое табло футбольных матчей: лента, разбор матча, журнал сигналов, фильтры,
подписка на уведомления, тарифы и кабинет. Тёмная тема, стеклянные поверхности,
анимации на каждом изменении данных.

**Стек:** React 19 · TypeScript · Vite 7 · zustand 5 · motion 12. Без UI-библиотек —
все поверхности свои, в `src/styles/`.

## Запуск

```bash
npm ci
npm run mock        # локальный API на http://127.0.0.1:8091
npm run dev         # http://localhost:5173/app/
```

Открывать нужно `http://localhost:5173/app/` — приложение живёт на базе `/app/`.
Дев-сервер проксирует `/app/api` на мок, поэтому данные настоящие по форме и
шевелятся сами.

Сборка и проверка:

```bash
npm run build       # типы + сборка в dist/
npm run typecheck   # только типы
npm run check       # скриншот в браузере: вёрстка + ошибки консоли
```

`npm run check` падает, если появилась горизонтальная прокрутка или ошибка в
консоли. Это дешёвая страховка: макет разъезжается тихо, а видно это потом.

## Как это должно выглядеть и вести себя

- **Одна стекло-поверхность на всё.** Новых цветов и теней не заводим — берём
  токены из `tokens.css`. Хочется оттенок — сначала переменная, потом использование.
- **Числа не выдумываются.** Нет значения — показываем «—». Нуль означает
  настоящую ноль, а не «данные не пришли».
- **Вероятность приходит с сервера в долях (0..1)**, перевес — в процентах.
  Путать их значит рисовать 0,64% вместо 64%.
- **Возраст данных считает сервер**, клиент только дотачивает его своими часами.
  На экране всегда видно, насколько свежая картина.
- **Каждое изменение данных — с анимацией**: число щёлкает, строка въезжает,
  бар срока тянется. Но `prefers-reduced-motion` обязателен, и он уже учтён.
- **Минимум текста на карточке:** сигнал, почему именно он, немного статистики.
  Отчёты на восемь блоков не читаются с телефона.

## Правила вёрстки, которые уже обошли дорого

Элементы `display: grid` по умолчанию не сжимаются ниже `min-content`. Широкая
таблица в grid-секции растягивает не только себя, но и шапку с подвалом — на
телефоне появляется горизонтальная прокрутка там, где её быть не должно. Лечится
`min-width: 0` на детях сетки; в `site.css` это уже сделано для `.site`, `.section`
и `.hero`.

## API

Контракт описан типами в `src/lib/api.ts` — это единственный источник правды по
форме ответов. Ошибки приходят одинаково: `{ error: { kind, message, retryable } }`.
Локально контракт закрывает `mock/server.mjs`; добавил эндпоинт во фронт — добавь
его в мок и в фикстуры, иначе проверка типов не заметит, а экран упадёт молча.
